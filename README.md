# 🧠 Synapsit

El juego de ciencia ciudadana para personalizar la neuromodulación.

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/lgonzalezpaz/synapsit/HEAD?urlpath=voila/render/app.ipynb)

## ¿Qué es Synapsit?

Synapsit es un juego de ciencia ciudadana donde los jugadores ajustan parámetros de receptores y neuromoduladores para mejorar el EEG de pacientes virtuales. Cada decisión que tomas contribuye a entrenar modelos de inteligencia artificial para neuromodulación personalizada.

## ¿Cómo jugar?

Haz clic en el badge de arriba 👆 o en este enlace directo:

https://mybinder.org/v2/gh/lgonzalezpaz/synapsit/HEAD?urlpath=voila/render/app.ipynb

## Características

- 🎛️ Panel de control con 9 perillas de receptores y neuromoduladores.
- 📊 Visualización en tiempo real del espectro EEG.
- 🏆 Ranking local de jugadores.
- 📖 Guía educativa integrada para cada parámetro.
- ☁️ Envío de resultados a Google Drive para análisis científico.
